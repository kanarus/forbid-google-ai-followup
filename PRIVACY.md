# Privacy Policy

Forbid Google AI Followup (FGAF) does not collect any data of any kind.

- FGAF has no home server, does never connects to a remote server.
- FGAF does not embed any analytic or telemetry hooks in its code.
- FGAF does not accept donations or any other form of finacing.

GitHub is used to host FGAF project. GitHub, Inc., a subsidary of Microsoft Corporation, owns GitHub and is unrelated to FGAF.
