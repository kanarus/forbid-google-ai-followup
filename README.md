<h1 align="center">
Forbid Google AI Followup
</h1>

For people feeling AI's followup extremely annoying, this extension dynamically analyzes AI's overview contents in https://www.google.com/search, detects followup part, and just removes it from user's sight.

<i><small>NOTE: occasionally produces false positives. (but in most cases it would not break the overview's meaning)</small></i>
