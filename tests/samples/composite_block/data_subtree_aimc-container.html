nvim lua に対する AI モードの回答

Neovim（v0.5以降）は、設定ファイルやプラグインの記述に Lua（LuaJIT）を標準でサポートしています。 
基本設定ファイルの場所
  • Linux / macOS: ~/.config/nvim/init.lua
  • Windows: %LOCALAPPDATA%\nvim\init.lua
  • モジュール分割時は ~/.config/nvim/lua/ 以下にファイルを置き、require("<モジュール名>") で読み込みます。 
よく使う基本API
  • エディタの設定（vim.opt） 
    lua
    vim.opt.number = true        -- 行番号を表示
vim.opt.shiftwidth = 4       -- インデント幅
vim.opt.termguicolors = true -- 24bitカラー有効化
    コードは注意してご使用ください。
  • キーマップの設定（vim.keymap.set） 
    lua
    -- 例: ノーマルモードで leader + h で行末移動など
vim.keymap.set('n', '<leader>h', '$', { desc = 'Move to end of line' })
    コードは注意してご使用ください。
  • Vimscript関数・コマンドの実行
    • Vimscriptの関数呼び出し: vim.fn.expand('%:p')
    • Vimコマンドの実行: vim.cmd('colorscheme slate') 
  • 変数スコープ
    • vim.g（グローバル変数）、vim.b（バッファ変数）、vim.opt（オプション）など 
代表的なLua製プラグイン
  • プラグインマネージャ: lazy.nvim や Packer.nvim
  • LSP（言語サーバー）: nvim-lspconfig
  • シンタックス解析: nvim-treesitter.nvim
  • ファジーファインダー: telescope.nvim
  • スターターテンプレート: kickstart.nvim
