    vitest happy-dom DOMException [NotSupportedError]: Failed to load external stylesheet に対する AI モードの回答

    This error occurs because happy-dom tries to fetch external <link rel="stylesheet"> URLs over the network during tests, and fails when the URL is relative, mocked, offline, or restricted. 
    You can fix this by disabling external resource loading in your Vitest configuration or setup file. 
    1. Disable CSS Loading in vitest.config.ts (Recommended)
    Configure environmentOptions.happyDOM.settings to ignore external stylesheets and other remote assets. 
    ts
    import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    environment: 'happy-dom',
    environmentOptions: {
      happyDOM: {
        settings: {
          disableCSSFileLoading: true,
          // Optional: prevent other external resource errors (images, scripts, iframes)
          handleDisabledFileLoadingAsSuccess: true,
        },
      },
    },
  },
});
    コードは注意してご使用ください。
    • disableCSSFileLoading: true. Prevents happy-dom from attempting to fetch <link rel="stylesheet"> files.
    • handleDisabledFileLoadingAsSuccess: true. Resolves disabled file loads cleanly instead of throwing DOMException [NotSupportedError]. 
    2. Configure Globally in a Vitest Setup File
    If you are using an older version of Vitest where environmentOptions does not pass settings properly, set it directly on the global happyDOM instance inside your setupFiles script. 
    ts
    // vitest.setup.ts
if (window.happyDOM) {
  window.happyDOM.settings.disableCSSFileLoading = true;
  window.happyDOM.settings.handleDisabledFileLoadingAsSuccess = true;
}
    コードは注意してご使用ください。
    3. Check css Processing in Vitest
    If the error happens when importing local .css files in components rather than <link> tags in HTML, ensure Vitest is not trying to evaluate raw stylesheets without transforming them. 
    ts
    // vitest.config.ts
export default defineConfig({
  test: {
    environment: 'happy-dom',
    css: false, // Ignores CSS imports during tests
  },
});
    コードは注意してご使用ください。
    If the error still happens after updating your config, let me know:
    • Your Vitest and happy-dom versions
    • Whether the stylesheet is an external <link> tag or a CSS module import
    I can help you narrow down the exact setting or mock needed.
